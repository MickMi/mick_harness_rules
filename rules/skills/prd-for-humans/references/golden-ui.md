# 待办列表快速筛选

通用写法示例 · 虚构场景与数据，非用户项目原稿

## 背景

用户进入待办列表后，需要在已完成和未完成事项之间反复查找。本次提供状态筛选与标题搜索，帮助用户直接找到要处理的事项，不改变待办的创建和处理方式。

## 用户动线

用户打开待办列表，选择「未完成」，再输入标题关键词缩小范围；点击一项进入详情，返回后保留刚才的筛选。需要重新查看全部内容时，点击「清空筛选」。

## 边界说明

没有匹配事项时显示「没有符合条件的待办」和清空入口，不将空结果误说成用户没有创建事项。加载失败时保留筛选条件并提供重试；不增加批量删除、导出或多套筛选方案。
